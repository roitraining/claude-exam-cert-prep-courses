# Prerequisites

- 1 to 5 years of software engineering experience with proficiency in Python or TypeScript
- At least 6 months of hands-on experience with Claude or comparable LLM systems
- Fluency with REST APIs and CLI tools
- Working knowledge of LLM fundamentals, agents, context management, and MCP
- For the labs: a paid Claude plan with Claude Code installed, a Claude Console API key with a few dollars of credit (created in Lab 0), Python 3.10 or newer, and a code editor such as VS Code
