# **Claude Certified Architect \- Foundations:**  **Hands-On Exam Prep Workshop**

**2 days**

## **Course Overview**

This two-day workshop prepares solution architects and technical practitioners to pass the Claude Certified Architect \- Foundations (CCAR-F) exam. Grounded in realistic production scenarios, the course covers all five exam domains so you can confidently evaluate architectural trade-offs with Claude.

You will master the exam blueprint through a blend of focused lectures, domain quizzes, four hands-on labs, and a final practice exam. Each module pairs conceptual review with scenario-based practice questions and guided exercises to get you ready for exam day.

## **Learning Objectives**

* Prepare for the Claude Certified Architect \- Foundations exam  
* Orchestrate multi-agent workflows and agentic loops with the Claude Agent SDK  
* Design effective tool interfaces and Model Context Protocol (MCP) integrations  
* Configure Claude Code hierarchies, custom skills, and CI/CD pipelines  
* Engineer reliable prompts and schema-compliant structured outputs  
* Manage conversation context, information provenance, and escalation workflows

## **Who Should Attend**

Solution architects and technical practitioners who design and implement production applications using the Claude API, Claude Agent SDK, Claude Code, and Model Context Protocol (MCP).

## **Prerequisites**

Attendees should have 6+ months of practical experience building with Claude in production environments, including familiarity with:

* The Claude API and Claude Agent SDK  
* Claude Code configuration and workflows  
* Model Context Protocol (MCP) integration  
* LLM capabilities, context management, and structured outputs
