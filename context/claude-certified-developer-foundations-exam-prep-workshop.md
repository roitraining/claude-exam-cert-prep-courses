# **Claude Certified Developer \- Foundations:**  **Hands-On Exam Prep Workshop**

**2 days**

## **Course Overview**

This two-day workshop prepares software and AI/ML engineers to pass the Claude Certified Developer \- Foundations (CCDV-F) exam. It walks through all eight exam domains to ensure you can confidently build, integrate, and ship production-ready applications and agents with Claude.

You will solidify your technical skills and test readiness through focused lectures, domain quizzes, four hands-on labs, and a final practice exam. Each module combines targeted instruction with practical coding exercises and review questions to prepare you for exam day.

## **Learning Objectives**

* Prepare for the Claude Certified Developer \- Foundations exam  
* Construct agents and workflows using the Claude Agent SDK  
* Integrate the Claude API into production applications  
* Operate Claude Code and debug applications through trace analysis  
* Optimize model selection, token usage, and prompt caching  
* Engineer prompts, context windows, and output validation  
* Secure AI applications with guardrails, hooks, and input defenses  
* Implement custom tools and Model Context Protocol (MCP) servers

## **Who Should Attend**

AI/ML engineers, software engineers, and technical leads who build, integrate, and ship production-ready applications, agents, and workflows using the Claude platform.

## **Prerequisites**

While there are no mandatory prerequisites to sit the exam, attendees should have:

* 1–5 years of software engineering experience (proficient in Python and/or TypeScript)  
* 6+ months of hands-on experience with Claude or comparable LLM systems  
* Fluency with REST APIs and CLI tools  
* Working knowledge of LLM fundamentals, agents, context management, and MCP
